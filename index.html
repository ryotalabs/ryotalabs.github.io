Building with Claude

In development: AnkiAI Capture. Photograph a textbook page, upload a lecture PDF, or paste meeting notes, and Claude turns it into a ready-to-study deck. Each card links back to the exact line it came from, so learners can check it before it enters their FSRS review schedule.

Claude handles reading the source (including handwriting and diagrams), choosing what is worth memorizing, and writing clear question-and-answer pairs. Users review and edit every card before saving it. Card generation is part of the premium plan.

Why Claude: Capture reads PDFs natively (text and page images), grounds every card with the Citations API so its source link comes from the API rather than model-written text, and emits cards through structured outputs. Prompt caching and the Batches API keep a full textbook deck inside the subscription's margin. Read the technical design.
